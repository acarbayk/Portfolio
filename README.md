# Portfolio

Personal portfolio of Kaya Acarbay: https://kayaacarbay.netlify.app

Plain HTML, CSS and JavaScript. No build step.

- Turkish / English switch and light / dark theme
- Self-hosted fonts (Manrope, Pixelify Sans)
- Contact form handled by Netlify Forms

## Run locally

    python3 -m http.server 8000

Then open http://localhost:8000

## Deploy

Connect the repository to Netlify. Build command: none. Publish directory: `/`.
